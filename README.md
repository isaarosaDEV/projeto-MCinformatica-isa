# Duas Luas, Um Destino

**Projeto Final — Curso Técnico MC Informática**

Site em Scroll Storytelling que conta a jornada de Luke Skywalker, do deserto de Tatooine à sua transformação em herói da Rebelião.

## 📖 Sobre o projeto

O objetivo deste projeto é aplicar a técnica de **Scroll Storytelling** — narrativa guiada pela rolagem da página — para contar uma história de forma imersiva e visual. A narrativa escolhida foi a trajetória de Luke Skywalker, estruturada em capítulos que se revelam conforme o usuário rola a página.

## 🎯 Objetivo

Contar a história de Luke Skywalker usando Scroll Storytelling, unindo narrativa, design visual e interatividade em uma experiência web fluida.

## ✨ Funcionalidades

- **10 capítulos narrativos**, cada um com sua própria ambientação visual
- **Rastreador de duas luas** (dual-moon tracker), remetendo às luas gêmeas de Tatooine, que acompanha o progresso da leitura/rolagem
- **Paletas de cores dinâmicas por capítulo**, refletindo o tom emocional de cada momento da história
- **Design responsivo**, adaptado para desktop, tablet e mobile
- Ilustrações e tratamento de imagem produzidos em Adobe Illustrator e Photoshop

## 🛠️ Tecnologias utilizadas

| Tecnologia | Uso |
|---|---|
| HTML | Estrutura do site |
| CSS | Estilização, paletas por capítulo e responsividade |
| JavaScript | Lógica de scroll, transições entre capítulos e rastreador das luas |
| Adobe Illustrator | Criação de ilustrações vetoriais |
| Adobe Photoshop | Tratamento e edição de imagens |
